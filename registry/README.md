# MCP Registry submission package

`server.json` is a draft remote-server manifest using the official MCP Registry `remotes` format for Streamable HTTP.

The Registry is in preview. The proposed name is
`io.github.dubbleblack/skipole-connect`, backed by the existing GitHub owner.
The manual distribution workflow validates the manifest and publishes it using
the official publisher's GitHub Actions OIDC flow, without new credentials or
DNS changes. Check the workflow and Registry response for actual publication.
Registry inclusion does not establish paid MCP verification or platform approval.

The website's canonical domain is `https://skipoledata.com`. The MCP endpoint remains on the existing Replit host until a custom-domain endpoint is separately verified.
