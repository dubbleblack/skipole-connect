# Contributing

This directory is prepared for a possible public repository. It is licensed under Apache-2.0, but repository publication and public contributions are not yet authorized.

Before a public release:

1. Confirm the public repository owner and review the package contents under `LICENSE`.
2. Run the JavaScript and Python SDK tests.
3. Review generated files and examples for credentials, customer records, private provider schemas, and internal billing implementation.
4. Update the changelog and security policy.
5. Do not publish package releases or submit platform listings without explicit approval.
